# Демонстрационные данные

SQL-файлы наполняют базу реалистичными данными для портфолио: сотрудники,
компьютеры и серверы, оргтехника, заявки с комментариями, сеть, Active Directory,
установленное ПО, компоненты компьютеров, расходники и журнал активности.

Скрипты идемпотентные: повторный запуск не создаёт дубликатов. Заявки и журнал
активности при повторном запуске пересоздаются, чтобы демо-данные оставались
предсказуемыми.

## Запуск

Файлы выполняются по порядку. Из корня репозитория:

```powershell
$env:PGPASSWORD='12345678'
$psql = 'C:\Program Files\PostgreSQL\17\bin\psql.exe'
Get-ChildItem backend\seeds\*.sql | Sort-Object Name | ForEach-Object {
  & $psql -h localhost -p 5433 -U postgres -d it-admin-s -v ON_ERROR_STOP=1 -f $_.FullName
}
```

Перед запуском должны быть применены миграции бэкенда и заполнены справочники
(подразделения, должности, локации, каталог ПО, типы техники). На чистой базе
это делает приложение при старте.

## Состав

| Файл                         | Содержимое                                                       |
| ---------------------------- | ---------------------------------------------------------------- |
| `01_employees.sql`           | 12 сотрудников, включая директора, бухгалтерию, продажи, HR и IT |
| `02_computers.sql`           | 14 компьютеров и серверов с гарантиями и статусами               |
| `03_equipment.sql`           | Принтеры, МФУ, сканер, ИБП, проектор и IP-телефоны               |
| `04_requests.sql`            | 15 заявок во всех статусах, SLA и комментарии                    |
| `05_network.sql`             | Сегменты, сетевые устройства, IP-адреса и история сканирований   |
| `06_ad.sql`                  | Группы, учётные записи и членство в группах                      |
| `07_software_components.sql` | Установленное ПО, компоненты ПК и замеры мониторинга             |
| `08_consumables.sql`         | Расходники и движения по складу                                  |
| `09_activity_log.sql`        | Журнал активности за последнюю неделю                            |
